# **AI Systems Builder Program**

### **From Machine Learning to LLMs and Agents**

---

## **1\. Overview**

The **AI Systems Builder Program** is a hands-on, project-driven course designed to help learners build real-world AI systems—from traditional machine learning models to advanced LLM-powered applications and autonomous agents.

Unlike theory-heavy programs, this course focuses on **practical system design, deployment, and real-world use cases**, ensuring learners can build and deploy production-ready AI solutions.

---

## **2\. Objectives**

By the end of this program, participants will be able to:

* Identify when and where AI should be used  
* Build end-to-end machine learning systems  
* Understand and apply NLP and Large Language Models (LLMs)  
* Develop LLM-powered applications using memory and RAG  
* Design and deploy agent-based systems for real-world tasks  
* Evaluate AI systems based on performance, reliability, and cost

---

## **3\. Target Audience**

* Non-technical learners looking to enter AI  
* Engineering students and graduates  
* Professionals seeking practical AI skills  
* Entrepreneurs building AI-driven products

---

## **4\. Course Structure**

### **Module 0: Thinking Like an AI Builder**

* When to use AI (and when not to)  
* System thinking vs model thinking  
* Real-world constraints: cost, latency, reliability

---

### **Module 1: Machine Learning Systems**

* Claude Code setup and usage  
* Problem framing: regression, classification, time series  
* Data leakage and feature engineering  
* Model evaluation: accuracy vs business metrics  
* Deployment fundamentals

**Project:**  
Build and deploy a machine learning system (e.g., prediction or demand forecasting)

---

### **Module 2: NLP and LLM Foundations**

* Traditional NLP techniques  
* Limitations of classical models  
* Introduction to LLMs  
* Prompt engineering basics  
* Structured outputs and reliability

**Project:**  
Build a text analysis system and upgrade it using LLMs

---

### **Module 3: LLM Applications (RAG Systems)**

* Memory in AI systems  
* Retrieval-Augmented Generation (RAG)  
* Document ingestion and chunking  
* Vector database fundamentals  
* Failure modes of RAG  
* Introduction to Agentic RAG

**Project:**  
Build a document Q\&A system using real-world data

---

### **Module 4: Agentic AI Systems**

* What are agents and how they work  
* Core components: memory, tools, planning, execution  
* Model Context Protocol (MCP)  
* Agent design patterns  
* Evaluation and monitoring

**Project:**  
Build an AI agent for a real-world task (e.g., document analysis, research automation)

---

## **5\. Teaching Methodology**

* Project-based learning (one project per module)  
* Minimal theory, maximum application  
* Live demonstrations and guided builds  
* Real-world use cases  
* Continuous evaluation and feedback

---

## **6\. Tools and Technologies**

* Claude Code (primary development environment)  
* Python ecosystem (for ML)  
* LLM APIs  
* Vector databases (for RAG)  
* Basic deployment tools (APIs, dashboards)

---

## **7\. Deliverables**

Each participant will complete:

* 3-4 end-to-end AI projects  
* A deployed ML system  
* A working RAG-based application  
* A functional AI agent  
* A portfolio of real-world AI systems

---

## **8\. Duration and Format**

* Duration: 5 weeks (flexible based on audience)  
* Format:  
  * Live sessions  
  * Hands-on labs  
  * Assignments and projects

---

## **9\. Unique Value Proposition**

This program stands out by focusing on:

* **End-to-end system building**, not isolated concepts  
* **Real-world applications**, not toy examples  
* **Agentic AI**, a rapidly emerging paradigm  
* **Deployment and evaluation**, often ignored in traditional courses

---

## **10\. Potential Use Cases**

Participants will be able to build solutions such as:

* Document intelligence systems  
* Business process automation tools  
* AI-powered analytics dashboards  
* Research and data extraction agents  
* Compliance and tender analysis systems

---

## **11\. Conclusion**

The AI Systems Builder Program equips learners with the skills required to move beyond theoretical understanding and build impactful AI solutions.

It bridges the gap between **learning AI** and **applying AI in the real world**, preparing participants for the next generation of intelligent systems.
