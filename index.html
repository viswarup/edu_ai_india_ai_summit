Module 0

Thinking Like an AI Builder

When to use AI (and when not to). System thinking vs model thinking. Real-world constraints: cost, latency, reliability.

Module 1

Machine Learning Systems

Claude Code setup, problem framing, feature engineering, model evaluation, and deployment fundamentals. Build a prediction or demand forecasting system.

Module 2

NLP & LLM Foundations

Traditional NLP techniques, introduction to LLMs, prompt engineering, and structured outputs. Build a text analysis system and upgrade it using LLMs.

Module 3

LLM Applications (RAG Systems)

Memory in AI, Retrieval-Augmented Generation, vector databases, failure modes of RAG, and Agentic RAG. Build a document Q&A system.

Module 4

Agentic AI Systems

Agents, memory, tools, planning, Model Context Protocol (MCP), agent design patterns, evaluation and monitoring. Build an AI agent for real-world tasks.

Industry Reading & Discussion
